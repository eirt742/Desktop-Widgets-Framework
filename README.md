# 🧩 Desktop Widgets

### Маленькие виджеты. Большой порядок на рабочем столе.

**Desktop Widgets** — Windows-приложение для запуска веб-виджетов прямо на рабочем столе. Создавай интерфейсы на HTML, CSS и JavaScript, а приложение покажет их как отдельные окна и предоставит связь с C#-хостом.

## ✨ Что это такое?

Desktop Widgets превращает обычные веб-страницы в компактные виджеты рабочего стола. Часы, заметки, таймеры, панели мониторинга или собственные мини-приложения — интерфейс можно собрать привычными веб-технологиями, а управление окнами остаётся на стороне C# и WPF.

Проект находится в разработке. Архитектура уже разделяет Windows-хост, WebView2, API-мост и папки отдельных виджетов.

## 🚀 Возможности

- **Веб-виджеты на HTML/CSS/JS** — содержимое виджета отображается через Microsoft Edge WebView2.
- **Отдельные окна** — каждый установленный виджет запускается в собственном WPF-окне.
- **Работа с рабочим столом Windows** — в проекте есть Win32-механизмы для размещения окон виджетов на рабочем столе.
- **Режим редактирования** — переключение горячей клавишей `Ctrl + F9`.
- **Системный трей** — приложение может оставаться запущенным в фоне.
- **Запоминание расположения** — состояние открытых виджетов и их координаты сохраняются в `%LOCALAPPDATA%\DesktopWidgets\opened-widgets.json`.
- **Библиотека виджетов** — приложение обнаруживает папки виджетов и читает их `manifest.json`.
- **Иконки виджетов** — для папки виджета можно использовать собственный файл `icon.png`.
- **Связь JavaScript ↔ C#** — встроенный bridge позволяет веб-интерфейсу вызывать зарегистрированные методы хоста и получать события.

## 🖼️ Примеры виджетов

- Windows.
- .NET 10 SDK.

## ⚙️ Сборка и запуск

1. Склонируй репозиторий:

   ```bash
   git clone <URL-репозитория>
   ```

2. Открой `DesktopWidgets.App/DesktopWidgets.App.csproj` в Visual Studio.

3. Восстанови зависимости и собери проект:

   ```bash
   cd DesktopWidgets.App
   dotnet restore
   dotnet build
   ```

4. Запусти приложение:

   ```bash
   dotnet run
   ```

Папка `Widgets` копируется в выходную директорию приложения при сборке, поэтому пакеты виджетов должны находиться внутри неё.

## 🧱 Структура виджета

Каждый виджет — отдельная папка внутри `DesktopWidgets.App/Widgets/`. Имя папки используется как идентификатор виджета.

```text
DesktopWidgets.App/
└── Widgets/
    └── MyWidget/
        ├── manifest.json
        ├── icon.png
        ├── settings.json      # необязательный файл настроек
        └── web/
            ├── index.html
            ├── style.css
            └── main.js
```

### manifest.json

Минимальный пример манифеста с параметрами, которые использует текущая модель конфигурации:

```json
{
  "widget_description": "Описание моего виджета",
  "width": 300,
  "height": 180
}
```

- `widget_description` — описание для библиотеки.
- `width` — начальная ширина окна.
- `height` — начальная высота окна.

Имя виджета берётся из имени его папки.

### Иконка

Положи изображение `icon.png` рядом с `manifest.json`:

```text
Widgets/MyWidget/icon.png
```

Хост использует эту иконку для карточки виджета в библиотеке. Рекомендуется квадратное изображение с прозрачностью по необходимости.

## 🔌 JavaScript Bridge

Веб-страница виджета может отправить сообщение хосту через WebView2:

```javascript
const requestId = crypto.randomUUID();

window.chrome.webview.postMessage({
    id: requestId,
    method: "getWidgetInfo",
    args: []
});

window.chrome.webview.addEventListener("message", (event) => {
    const response = event.data;

    if (response.id !== requestId) return;

    if (response.success) {
        console.log("Ответ от Desktop Widgets:", response.result);
    } else {
        console.error("Ошибка bridge:", response.error);
    }
});
```

### Методы, зарегистрированные по умолчанию

| Метод | Аргументы | Назначение |
|---|---|---|
| `getWidgetInfo` | нет | Возвращает имя виджета и версию bridge |
| `setPosition` | `[x, y]` | Устанавливает координаты окна виджета |
| `minimize` | нет | Сворачивает окно виджета |

Хост также может отправлять события в страницу. Например, при переключении режима редактирования приходит сообщение с типом `onEditModeToggle` и полем `data.enabled`.

```javascript
window.chrome.webview.addEventListener("message", (event) => {
    const message = event.data;

    if (message.type === "onEditModeToggle") {
        console.log("Режим редактирования:", message.data.enabled);
    }
});
```

Другие методы могут быть добавлены в `WidgetBridgeManager` на стороне C#.

## 🧑‍💻 Как добавить свой виджет

1. Создай папку `DesktopWidgets.App/Widgets/MyWidget/`.
2. Добавь `manifest.json` с описанием и размерами окна.
3. Создай папку `web/` и добавь в неё `index.html`, `style.css` и `main.js`.
4. Добавь `icon.png` для отображения в библиотеке.
5. Собери и запусти приложение — папка виджета будет включена в выходную директорию благодаря правилу копирования `Widgets/**/*`.

**Подсказка:** начни с одного из существующих примеров в `Widgets/` и адаптируй его под свою задачу.
